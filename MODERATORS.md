## How to become a moderator

We want the moderation crew to grow as the project grows. The path in:

1. **Make at least 3 meaningful contributions** (merged PRs, not typo fixes). Shows you understand the voice and the material.
2. **Say you're interested** — open an Issue titled `moderator application: <your name>`, or DM an existing moderator.
3. **Sit in on 2 PR reviews** with an existing moderator, commenting alongside them.
4. **Get added** by any existing moderator once the above are done.

No vote, no drama. We're a small team — adding people is a judgment call by existing moderators.

## The moderator's job

### On a PR, you check for:

**Correctness**
- [ ] Claims are factually correct, or at least match what was taught in session.
- [ ] Numbers have sources cited (RBI / MoSPI / Tantri's slides / a paper / a textbook).
- [ ] No math errors in equations; units and signs are right.

**Clarity**
- [ ] A non-finance classmate could follow this.
- [ ] Jargon is defined on first use.
- [ ] There's at least one concrete example or tie-in to the real world.

**Form**
- [ ] Front matter is valid (`title`, `date`, `dek`, `tags`).
- [ ] Images are in `assets/images/<slug>/` with alt text.
- [ ] File name is `YYYY-MM-DD-slug.md` in `_posts/`.
- [ ] Links resolve (check with `bundle exec jekyll serve` locally if unsure).

**Conduct**
- [ ] Attribution to source material is honest.
- [ ] No plagiarism. No uncredited lifting from textbooks.

### On an Issue, you:

1. **Label it** (`bug`, `content-error`, `explainer-request`, `new-note`, `site`).
2. **Ask clarifying questions** if needed.
3. **Either fix it yourself** or leave a comment so someone else can pick it up. Add `good-first-issue` if it's a nice starter task.

### On a conflict:

Two moderators disagree about a change? Default behaviour:
1. Discuss in the PR thread.
2. If unresolved, leave the PR open and bring it to the next moderator sync.
3. Founding editors (Harsh, for now) have a tiebreaker vote, but we try not to use it.

## Moderator sync

Informal. Every few weeks, on Discord/WhatsApp. Agenda:
- Open PRs that are stuck.
- Editorial standards drift — anything we should add to the style guide.
- Who's taking the next batch of triage.

## What moderators do NOT do

- We don't gatekeep contributions. If someone writes something rough, we help them polish it, we don't reject it.
- We don't edit silently in someone else's PR — we request changes and explain.
- We don't merge our own PRs without another moderator's review.

## Emeritus

When someone stops being active, move them here. Still credited, no longer on-call.
