# Code of Conduct

Gen Z Economics is a space for students to learn macroeconomics together, in public. We expect everyone — contributors, moderators, commenters — to behave with the same basic respect you'd expect in a good classroom.

## The short version

- **Be kind.** Assume good faith. Most mistakes are honest.
- **Focus on the work, not the person.** "This claim isn't right" beats "you don't know what you're talking about."
- **Ask before you assume.** Ask clarifying questions before assuming someone got it wrong.
- **Give credit.** If an idea came from a classmate, a slide, or a paper, say so.

## Not OK

- Harassment, personal attacks, discrimination of any kind.
- Sharing someone's private information (phone, address, DMs).
- Sustained disruption — trolling, flooding issues, re-opening closed threads.
- Plagiarism or passing off someone else's work as yours.

## Reporting

If something happens that makes you uncomfortable — either in this repo, in an issue thread, or in a review — DM any moderator (listed in [`MODERATORS.md`](./MODERATORS.md)) or email [hello@genz-economics.com](mailto:hello@genz-economics.com).

Reports are confidential. Moderators will acknowledge within 72 hours.

## Consequences

Moderators may:
1. Warn privately.
2. Edit or remove a comment / commit / PR.
3. Temporarily block someone from contributing.
4. Permanently ban, for serious or repeated violations.

## Scope

This applies to everything in this repo and any official Gen Z Economics space (Discord, WhatsApp, email, in-person meetups).
